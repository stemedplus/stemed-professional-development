# Runbook: Professional Development

This board uses the shared STEMEd+ pipeline. For how every board works and the common fixes, see the [stemedplus-theme runbook](https://github.com/stemedplus/stemedplus-theme/blob/main/RUNBOOK.md).

| | |
|---|---|
| **Site** | stemedplus.github.io/stemed-professional-development |
| **Repository** | stemedplus/stemed-professional-development |
| **Updates** | Daily at 10:23 UTC, on push, and by hand (`update.yml`) |
| **Listings** | One file per program in `programs/`, checked against `schema/` |
| **Check / build** | `python -m stemed_pd --validate`, then the build |
| **Add or fix** | **Suggest a program** and **Update a program** issue forms |

This board combines the old Faculty Development and Professional Learning lists, with a filter by role. Their old addresses forward here through the redirect repositories `stemed-faculty-development` and `stemed-professional-learning` (see the theme runbook).

_Written November 2026. Review with the yearly December review._
